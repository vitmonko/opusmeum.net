On 18 November 2026, during Microsoft Ignite, Microsoft published its Copilot Studio update. The theme is business processes: agents that run longer, workflows that call agents, and more ways for IT to see what agents cost. Only some of it is generally available. The rest is in preview or arrives in December.

## What is new

- **Customer conversation harness is generally available.** It is built for customer-facing voice and chat agents and can hand a conversation to a live agent with its context.
- **Agent sharing is generally available.** Several makers can work on the same agent in Copilot Studio.
- **Apps in Copilot Studio and Copilot Cowork.** Microsoft says general availability is rolling out this month.
- **Agents and workflows from Copilot Cowork and Copilot Code are in public preview.** Users describe what they need in natural language, and the result lives in Copilot Studio, where IT can govern it like other organizational solutions.
- **Agent accounts enter public preview in December 2026.** Agents get managed credentials and access to approved resources.
- **Command-line tools and Copilot Studio MCP are in public preview.** Microsoft also describes a developer path for building and editing agents locally, with artifacts backed by GitHub repositories.
- **Microsoft Copilot harness.** The renamed harness handles reasoning, planning and orchestration, and Microsoft highlights hooks, computer use and MCP integration for reaching business systems.
- **Smarter workflow routing.** The classify node in workflows now uses a decision-scoring model by default, for tasks such as email triage.
- **Cost management dashboard.** It shows prepaid and pay-as-you-go credit usage, active users and estimated remaining credits, alerts on users and groups near their spending limits, and suggests where to move unused credits.

## Why it matters

The generally available parts are ready for production planning now, especially for customer service teams. The previews point to a bigger change: agents built by people outside IT, from tools they already use, and agents that act with their own credentials. Both make governance and cost control a day-one task rather than an afterthought.

## What to do now

1. **Separate GA from preview.** Plan pilots for the customer conversation harness and shared agent editing. Test the Cowork, Code and command-line previews in a non-production environment.
2. **Decide who may create agents from Cowork and Code.** Set environment and data policies in the Power Platform admin center before the preview spreads.
3. **Prepare for agent accounts.** Agree who approves the resources an agent may use and who owns each agent. Our post on [Copilot Studio agents with their own accounts](/news/copilot-studio-agents-own-accounts/) explains the background.
4. **Open the cost dashboard.** Set spending limits and alerts for credits, and name a person who reviews them each month.
